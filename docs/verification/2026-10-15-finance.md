# Internal finance ledger

Owner-only, per-user KRW cash ledger at /workspace/finance. Manual entry, edit with optimistic version guard, reversible archive/restore, monthly income/expense/net cash movement. No banking import, invoice issuance, automatic sends or bookkeeping-profit claim. Other CRM roles cannot access records. Existing CRM owner membership and database RLS apply independently of UI. UUID request IDs prevent duplicate create retry; fresh intentional entries are distinct. Database aggregates all active entries for the month independent of list filters or paging; totals are text integers rendered with BigInt.

Validation: PGlite tests cover owner isolation, operator/anonymous denial, protected ownership columns, constraints, duplicate insert, archive and restore sums, stale version rejection, audit records, month boundaries and invalid dates/amounts. Existing full test suite and Next build pass. Local desktop and 390px mobile editor visually checked with synthetic empty data. Preview route removed before commit. Production database migration applied; empty monthly summary verified. Security advisor has only pre-existing invites RLS info and leaked-password warning.
