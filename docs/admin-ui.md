# ERP 관리자 UI

사용자 제공 admin-ui-kit.zip의 디자인 토큰과 조회 화면 패턴을 적용했다.

- 짙은 사이드바 240/64px, 상단바 52px, 파란 강조색 #1447e6.
- 병원·제안서·영업 화면을 KPI, 검색조건, 단일 스크롤 표, 페이저로 통일.
- 자동 행 수는 실제 표 높이에서 계산하며 20/50/100 선택을 브라우저에 저장.
- 조회 전 초안 검색 상태와 URL 확정 상태 분리. 상세 수정일 검색은 한국시간 기준.
- 상세·추가·수정은 네이티브 dialog로 키보드 포커스와 Esc 닫기를 제공.
- CSV는 현재 페이지 범위이며 수식 접두어를 이스케이프한다.
- 인증·RLS·원본 데이터 변경 없음. 조회 정렬은 updated_at와 id로 안정화.
- 병원 선택 최대 1,000건 제한은 기존과 동일.
